# Fatima tu Zahra Website Update

This package is ready to upload to the existing GitHub repository.

## Files
- `index.html`
- `assets/styles.css`
- `assets/images/` (optimized competition photos)
- `assets/video/` (place the existing `Fatima USPA.mp4` here)

## To update the GitHub site
1. Open the existing repository: `Fatima-tu-Zahra-Athlete`.
2. Replace the old `index.html` with this new `index.html`.
3. Upload the entire `assets` folder.
4. If you have the original `Fatima USPA.mp4`, create `assets/video/` and upload it there.
5. Commit the changes.
6. GitHub Pages will update automatically after the commit.

## Optional video activation
After uploading the MP4, replace the `video-placeholder` block in `index.html` with:

<video controls preload="metadata" poster="assets/images/hero.jpg" class="competition-video">
  <source src="assets/video/Fatima USPA.mp4" type="video/mp4">
  Your browser does not support embedded video.
</video>
